# Number Guessing Game

A command-line number guessing game developed using Python.

## Features

- Random number generation
- Three difficulty levels
- Limited guessing attempts
- High and low hints
- Score calculation
- Guess history
- Player leaderboard
- JSON-based score storage
- Input validation
- Replay functionality

## Technologies

- Python 3
- JSON
- Unittest

## Installation

Clone the repository:

    git clone https://github.com/michaelwawiny/python-project-02-number-guessing-game.git

Navigate into the project:

    cd project-02-number-guessing-game

## Run the application

    python3 main.py

## Run tests

    python3 -m unittest discover -s tests -v
